HL CLIENT ENGINE — ОДИН ЛАУНЧЕР ДЛЯ ГРИ ТА ДІАГНОСТИКИ

Архів: HLClientEngine-Win10.zip.
Запуск: HLClientLauncher.exe у папці HLClientEngine.
Це той самий Windows-лаунчер із налаштуваннями відео, HUD, звуку та
прапорцями діагностики. Окремого «лаунчера без діагностики» немає.

ПЕРШИЙ ЗАПУСК

1. Розпакуйте ВСЮ папку HLClientEngine, наприклад у C:\Games\HLClientEngine.
   Не запускайте EXE всередині ZIP. Залиште EXE та DLL разом.
   Старі пакети Start-HLClient.cmd більше не потрібні. Не змішуйте файли
   з різних архівів — цей комплект уже повний.
   Права адміністратора та встановлення засобів розробки не потрібні.

2. Встановіть ліцензійну Half-Life через власний Steam, запустіть Steam
   і ввійдіть у свій обліковий запис. Steam та файли гри не включені.

3. Відкрийте HLClientLauncher.exe. У «Локальні ресурси (додатково)»
   натисніть «Папка…» біля Half-Life й виберіть корінь установленої гри,
   наприклад C:\Program Files (x86)\Steam\steamapps\common\Half-Life.
   Це папка, що містить valve, а не сама valve чи папка цього комплекту.
   Якщо в полі залишився шлях з іншого ПК, замініть його кнопкою «Папка…».

   У Steam DLL потрібний офіційний 32-бітний steam_api.dll із цієї
   інсталяції Half-Life. Вибір папки підставляє <Half-Life>\steam_api.dll;
   за потреби скористайтеся «Файл…». Не копіюйте його до цього пакета.

4. Введіть адресу свого сервера у форматі IPv4:порт та ім'я гравця.
   У «Відео» виберіть монітор, роздільність і режим. Для першого тесту
   слабшого ПК рекомендується явно вибрати «Згладжування: Вимкнено».
   MSAA 2x/4x/8x можна перевірити після успішного запуску.
   Пакет самостійно не змінює ваш вибір MSAA або VSync.

   Віконний режим використовує заданий розмір вікна. Повноекранний без
   рамки використовує поточний робочий стіл вибраного монітора.
   Прапорець «Віконний режим»: увімкнений — вікно, вимкнений —
   повноекранний без рамки. Для нового профілю типовий повноекранний режим.
   «Показувати FPS» вмикає читабельний лічильник без команд у консолі.
   Цей прапорець не змінює fps_max або VSync.
   HUD, яскравість, гамма, контраст і гучність налаштовуються в цьому ж
   вікні; прокрутіть його, щоб дістатися нижніх кнопок.

5. Для звичайної гри можна зняти ОБИДВА прапорці:
   — «Комплексна діагностика гри»;
   — «Системна діагностика CPU/GPU».
   Додаткові ігрові та системні записи тоді не збираються. Невеликий
   журнал запуску з причиною помилки зберігається завжди.

   Натисніть «Підключитися». «Відкрити клієнт» відкриває консоль без
   автоматичного підключення до сервера.

ЯК ПЕРЕДАТИ ПОМИЛКУ, ЯКЩО КЛІЄНТ НЕ ЗАПУСКАЄТЬСЯ

6. Повторіть запуск один раз. Прапорці діагностики вмикати для цього
   не потрібно. Після помилки натисніть «Зберегти ZIP логів…» у тому самому
   лаунчері й передайте створений ZIP у чат. «Папка логів запуску»
   відкриває відповідну папку в Провіднику.

   Журнали містяться в:
       %LOCALAPPDATA%\HLClientEngine\startup\<час-PID-ідентифікатор>

   Резервний шлях, якщо звичайне сховище недоступне:
       %TEMP%\HLClientEngine\startup

   launcher-startup.log містить етапи запуску лаунчера/клієнта та причину
   збою. client-startup.log містить очищений текстовий вивід запущеного
   клієнта, коли той встиг його створити. Журнали мають обмежений розмір.
   Якщо клієнт взагалі не створився, причину шукайте в launcher-startup.log.

   Якщо вікно самого лаунчера не з'явилося, відкрийте вказану startup-папку
   через Провідник і заархівуйте найновішу підпапку вручну. Це не потребує
   запуску гри, Steam-авторизації чи комплексної діагностики.
   Файли повинні міститися в одному каталозі з EXE; не завантажуйте
   відсутні DLL із випадкових сайтів.

ЯК ЗАПИСАТИ FPS, РИВКИ АБО PREDICTION ПІД ЧАС ГРИ

7. Увімкніть «Комплексна діагностика гри» перед потрібним запуском.
   За потреби додатково ввімкніть «Системна діагностика CPU/GPU».
   Для системного запису HLClientSystemDiagnostics.exe має залишатися
   поруч із лаунчером. Відсутні датчики/counters позначаються як
   partial/unsupported і самі по собі не заважають грі.

   Натисніть F8 під час проблеми, потім штатно закрийте гру й дочекайтеся
   завершення запису. Для аналізу FPS/prediction заархівуйте ПОВНУ папку
   цього Run ID (32 шістнадцяткові символи) з:
       %LOCALAPPDATA%\HLClientEngine\runs

   Кнопка «Зберегти ZIP логів…» призначена для помилок запуску.
   Вона не замінює повний ігровий Run ID. Окремий system-diagnostics.zip
   також може не містити великий external-movement.json.
   Шляхи, ігрові імена й адреси сервера можуть бути в ігрових звітах;
   перегляньте їх перед публікацією у відкритому доступі.

8. Для вимірювання запасу FPS можна явно вимкнути VSync у лаунчері,
   а в ігровій консолі ввести:
       fps_max 0
       cl_showfps 1
   Після тесту поверніть власні налаштування.

ВИМОГИ ТА СКЛАД КОМПЛЕКТУ

Потрібні Windows 10 x64 із сумісністю x86/WOW64, SSE2 та драйвер виробника
відеокарти з OpenGL 3.3 Core. Оновлюйте Windows і драйвер штатними засобами.
Потрібні бібліотеки Visual C++ x86 включено поруч із EXE; окреме встановлення
runtime для цього комплекту не потрібне. Visual Studio, CMake, Git, Codex,
Python, PowerShell 7, ADK або HWiNFO для запуску не потрібні.

Steam, офіційний steam_api.dll, карти, моделі, спрайти, текстури й звуки
надходять із власної встановленої Half-Life. Пакет їх не розповсюджує.
Налаштування зберігаються в %LOCALAPPDATA%\HLClientEngine\launcher.json;
архів не містить і не перезаписує ваші персональні налаштування.
На іншому ПК не потрібні диск D: чи дерево вихідного проєкту.

Клієнт гри збережено без перебудови від прийнятої ігрової версії:
SHA-256 E044684FE00E688F555988478E83E7DEF037EC35844C05F19E7B540C45CAA32C.
Лаунчер оновлено для єдиного запуску та журналів помилок. Попередня
прийнята гра не є окремим ігровим тестом нового лаунчера.
Точні хеші, залежності й перевірки наведені в BUILD_INFO.json;
SHA256SUMS.txt перевіряє комплектність.

Офлайн-перевірка на машині розробника не замінює запуск на вашому Windows 10.
Фактичного тесту на Windows 10 під час пакування не було:
windows10_runtime=not_run.
